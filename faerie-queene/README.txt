THE FAERIE QUEENE — Edmund Spenser
A complete illustrated web edition in modernized spelling.

CONTENTS
  index.html            the edition (text, navigation, ornaments)
  assets/img/           38 plates and pages, public domain, via Wikimedia Commons
  assets/fonts/         IM Fell types (digitized by Igino Marini, SIL OFL)
                        and EB Garamond (Georg Duffner, SIL OFL)

                        the same edition as a single self-contained file

HOSTING
  Upload the directory as-is; index.html at the root. No server-side
  code, no external requests, no cookies, no analytics. Everything is
  static and relative-pathed; it will serve from any host, including
  a bare S3 bucket or GitHub Pages.

TEXT
  J. C. Smith's Clarendon edition (Oxford, 1909), via Project Gutenberg
  eBooks #70717 and #72698, spelling modernized as described in the
  edition's Note on the Text. The poem is in the public domain.

The plates are public-domain works by Walter Crane, Henry Fuseli,
William Etty, Benjamin West, J. M. W. Turner, G. F. Watts, Briton
Riviere, Washington Allston, Thomas Uwins, John Melhuish Strudwick,
Fernand Khnopff, and others; sources are itemized in the colophon.
