# Raw fetched source pages

Verbatim dumps of pages fetched during witness research, kept as an audit
trail for the Greek text used in `sappho/src/fragments.json` (once built).
Per `sappho/CLAUDE.md`'s sourcing rule, no Greek text in this project is
taken from a model's memory — everything traces back to a real fetched page
like these.

- `wikisource_epigrammata.txt` — Greek Wikisource, "Επιγράμματα" (Sappho),
  Greek text as arranged in Bergk's *Poetae Lyrici Graeci*, transcribed from
  Edmonds' 1922 *Lyra Graeca* (US public domain).
- `wikisource_ymnoi.txt` — Greek Wikisource, "Ύμνοι - Επιθαλάμια", Greek text
  per Wharton's 1895 *Sappho* edition (public domain).

Both are MediaWiki markup as fetched from el.wikisource.org.
